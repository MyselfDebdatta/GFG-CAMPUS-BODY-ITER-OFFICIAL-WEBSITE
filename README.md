# GFG Campus Body ITER

Welcome to the official repository for the GeeksforGeeks student chapter at ITER, SOA University.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating) or use Bun.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
